Generador de código de barras

Revisada en noviembre de 2026

Elige el tipo de código, escribe tu número y el código de barras aparece al momento. Si es EAN o UPC, la herramienta calcula el dígito verificador.

Lo bajas en PNG o SVG, o en una hoja tamaño carta llena de etiquetas para imprimir. No pide cuenta. El PNG y la hoja llevan abajo una línea gris chica de Aliviane.

Cómo crear tu código de barras

  1. Elige el tipoEAN-13 para productos en tienda. CODE128 para inventario, folios y envíos.
  2. Escribe el númeroEn EAN-13 pon 12 dígitos y sale el último. Si pones 13, la herramienta revisa que esté bien.
  3. Ajusta el tamañoCambia el grosor de las barras y su alto. Decide si muestras los números abajo.
  4. Descarga o arma tu hojaPNG o SVG para tu etiqueta. La hoja de etiquetas sale en PDF carta.

El dígito verificador

El último número de un EAN o un UPC no se inventa. Sale de una cuenta con los demás dígitos.

Sirve para que el lector detecte un número mal leído. Si escribes los 13 dígitos y el último no cuadra, la herramienta te dice cuál debería ser.

Códigos para vender en tiendas grandes

Para vender en cadenas y supermercados de México necesitas un código registrado. Los asigna GS1 México, el organismo que emite y administra estos códigos en el país.

El prefijo 750 indica que el código se registró en México. No dice que el producto se fabricó aquí.

Esta herramienta dibuja el código del número que escribas. No te da un número registrado ni sustituye el trámite con GS1.

Para tu inventario, tu tienda o tu bodega no necesitas registro. Usa CODE128 con tus propias claves y listo.

La hoja de etiquetas

Abre «Hoja de etiquetas para imprimir» y elige la medida de tus etiquetas adhesivas. Hay medidas de 10, 21, 30 y 80 por hoja.

Puedes repetir el mismo código o pegar una lista con un código por renglón. La hoja sale en PDF lista para imprimir.

  • Imprime una hoja de prueba y pásala por tu lector.
  • Usa impresora láser para barras más nítidas.
  • No reduzcas el código por debajo de lo que tu lector alcanza a leer.
  • Deja el margen blanco a los lados del código.

Si haces notas para tus entregas usa la nota de remisión. Para dar precios a tus clientes arma tu lista de precios.

Preguntas frecuentes

¿El generador de código de barras es gratis?

Sí. Sin cuenta y sin límite de códigos. El SVG sale sin la línea chica de Aliviane que lleva el PNG.

¿Puedo vender en supermercados con estos códigos?

No sin registro. Las cadenas piden un código asignado por GS1 México.

¿Qué código uso para mi inventario?

CODE128. Acepta letras y números y lo lee cualquier lector.

¿Qué es el dígito verificador?

El último número de un EAN o UPC. Sale de una cuenta con los demás dígitos.

¿En qué formato lo mando a imprimir?

En SVG o en la hoja PDF. Los dos imprimen las barras nítidas.

¿Puedo hacer muchos códigos distintos en una hoja?

Sí. Pega tu lista con un código por renglón en la hoja de etiquetas.
