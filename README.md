# aliviane.mx

Sitio de Aliviane en GitHub Pages (rama `main`, raíz). No se borra el archivo `CNAME`.

- `index.html`: la página de la agencia.
- `sitios/<negocio>/`: las muestras que se le mandan a cada negocio. Las genera el taller (`aliviane-taller`), no se editan a mano. Llevan `noindex` y `robots.txt` las bloquea.
