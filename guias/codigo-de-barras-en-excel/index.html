Cómo hacer códigos de barras en Excel

Revisada en noviembre de 2026

Excel no trae una función para dibujar códigos de barras. Lo más común es usar una fuente de código de barras, un complemento o pasar tu lista a un generador.

Para Code 39 basta una fuente y poner asteriscos al inicio y al final. Para EAN-13 o Code 128 conviene un generador, como el de abajo, que calcula el código completo y arma la hoja en PDF.

Por qué Excel no hace códigos de barras solo

Excel guarda números y textos en celdas. Un código de barras es un dibujo que sigue reglas de cada tipo.

Excel no trae una función que dibuje esas barras. Por eso hay que usar un truco o una herramienta aparte.

Hay tres caminos. Cada uno sirve para algo distinto.

Para la mayoría de negocios pequeños, el tercero es el más seguro. La herramienta de arriba hace eso sin instalar nada.

Método 1, la fuente de Code 39

Code 39 es un tipo de código que acepta mayúsculas, números y algunos signos. Es el más fácil de hacer con una fuente.

La fuente Libre Barcode 39 es gratuita y de licencia abierta. La bajas de Google Fonts y la instalas en tu computadora.

Pasos

  1. Instala la fuenteDescarga Libre Barcode 39, abre el archivo y toca instalar.
  2. Escribe tus códigosEn la columna A pon tus códigos en mayúsculas, por ejemplo ALM-0012.
  3. Agrega los asteriscosEn la columna B escribe la fórmula ="*"&A2&"*" y arrástrala hacia abajo.
  4. Cambia la letraSelecciona la columna B y elige la fuente Libre Barcode 39.
  5. Agranda el tamañoSube la letra a 36 o más para que el lector la lea.
  6. Prueba antes de imprimirImprime una hoja y pásala por tu lector.

Los asteriscos son obligatorios en Code 39. Marcan dónde empieza y dónde termina el código.

Si olvidas los asteriscos, el lector no leerá nada. Es la falla más común con este método.

Por qué la fuente no sirve para todos los tipos

EAN-13 y Code 128 no son sólo letras con otra forma. Llevan cálculos y caracteres especiales que una fuente no hace sola.

EAN-13 lleva un dígito verificador y una estructura por mitades. Code 128 lleva un carácter de control calculado.

Con una fuente sin esos cálculos, el código se ve bien pero el lector lo rechaza. Por eso para esos tipos conviene un generador.

Método 2, complementos y macros

Hay complementos que agregan una función de código de barras a Excel. Algunos son gratuitos y otros de pago.

También se puede escribir una macro que calcule el código. Requiere saber programar en el editor de Excel.

Antes de instalar un complemento, revisa quién lo hace y qué permisos pide. Tu archivo puede tener precios y datos de clientes.

Método 3, de Excel al generador en un minuto

Este método usa tu lista de Excel y la herramienta de arriba. No instalas nada y el resultado sale en PDF.

  1. Selecciona la columnaEn Excel marca la columna con tus códigos, sin el título.
  2. CopiaUsa copiar como siempre.
  3. Elige el tipo arribaEn la herramienta selecciona EAN-13, Code 128 u otro tipo.
  4. Pega en la listaPega en el cuadro de códigos de la hoja, uno por renglón.
  5. Elige la medida de etiquetaSelecciona la que coincide con tus hojas de etiquetas.
  6. Baja el PDFDescarga la hoja tamaño carta y mándala a imprimir.

La herramienta revisa cada renglón. Si un código no sirve para el tipo elegido, te dice en qué renglón está.

En EAN-13 puedes pegar 12 dígitos y la herramienta calcula el verificador. Si pegas los 13, revisa que el último sea correcto.

Cómo se calcula el dígito verificador de EAN-13

El último número de un EAN-13 sirve para detectar errores de lectura. Se calcula con los primeros doce.

Cálculo del verificador con el ejemplo 750123456789
PasoQué hacesResultado del ejemplo
1Suma los dígitos en posición impar7 + 0 + 2 + 4 + 6 + 8 = 27
2Suma los dígitos en posición par5 + 1 + 3 + 5 + 7 + 9 = 30
3Multiplica la suma par por tres30 × 3 = 90
4Suma los dos resultados27 + 90 = 117
5Busca cuánto falta para la siguiente decena120 − 117 = 3

El verificador del ejemplo es 3. El código completo queda 7501234567893.

Si la suma ya termina en cero, el verificador es cero. La herramienta hace este cálculo sola al pegar doce dígitos.

Para guardarlos como texto, selecciona la columna y cambia el formato de celda a texto antes de escribir.

Leer códigos de barras hacia Excel

Un lector de código de barras común funciona como un teclado. Escribe el número en la celda donde está el cursor.

Por eso puedes usar Excel para contar inventario. Pones el cursor en la columna de códigos y vas escaneando.

Casi todos los lectores dan un salto de renglón después de cada código. Así el cursor baja solo a la siguiente celda.

Si quieres saber cuántas piezas tienes de cada código, usa la función CONTAR.SI. Cuenta cuántas veces aparece cada código en la columna.

En Google Sheets

En Google Sheets el método de la fuente también funciona. La familia Libre Barcode 39 se puede elegir desde el menú de fuentes.

Escribe la misma fórmula con asteriscos y cambia la letra de la columna. Las mismas limitaciones aplican para EAN-13 y Code 128.

Para imprimir etiquetas, copia la columna de Sheets y pégala en la herramienta de arriba. Funciona igual que con Excel.

Ejemplo de una tienda de abarrotes en Puebla

Este es un ejemplo inventado. Una tienda tiene 300 productos en Excel y quiere etiquetar su anaquel.

Primero separó los productos de marca, que ya traen código de fábrica. Esos no necesitan etiqueta nueva.

Para los productos a granel creó códigos internos en Code 128, como GRANEL-001. Los pegó en la herramienta y bajó tres hojas de 30 etiquetas.

Imprimió una hoja de prueba y la pasó por su lector. Cuando leyó bien, imprimió las demás.

Agregó una columna de código en su Excel de precios. Ahora cobra escaneando y busca precios con el código en lugar del nombre.

Cada vez que llega un producto nuevo a granel, le da el siguiente número de la serie. Así nunca repite un código.

Errores comunes

  • Usar la fuente de Code 39 sin asteriscos.
  • Usar una fuente para EAN-13 sin calcular el verificador.
  • Dejar que Excel convierta los códigos en notación científica.
  • Imprimir la hoja con ajuste a página.
  • Imprimir cientos de etiquetas sin probar una primero.
  • Inventar números EAN-13 para vender en cadenas.
